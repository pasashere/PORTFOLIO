# Portfolio Website - Farid Isgandarli

A professional portfolio website for Farid Isgandarli, SOC Analyst & Cybersecurity Specialist.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional design with cybersecurity-themed color scheme
- **Interactive Elements**: Smooth scrolling, animations, and hover effects
- **Matrix Rain Effect**: Cybersecurity-themed background animation
- **Sections**:
  - Hero section with introduction
  - About section highlighting expertise areas
  - Technical skills organized by categories
  - Professional experience timeline
  - Contact information with social links

## Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- Vanilla JavaScript
- Font Awesome icons

## How to Use

Simply open `index.html` in a web browser to view the portfolio website.

For local development with a web server:
```bash
python3 -m http.server 8080
```

Then navigate to `http://localhost:8080` in your browser.

## Customization

To customize the portfolio:

1. **Update Personal Information**: Edit `index.html` to update name, bio, skills, and experience
2. **Change Color Scheme**: Modify CSS variables in `styles.css` under `:root`
3. **Add/Remove Sections**: Edit the HTML structure in `index.html`
4. **Modify Animations**: Adjust JavaScript effects in `script.js`

## Color Scheme

The website uses a cybersecurity-themed dark color palette:
- Primary Green: `#00ff88`
- Accent Cyan: `#00d4ff`
- Dark Background: `#0a0e27`
- Darker Background: `#050814`
